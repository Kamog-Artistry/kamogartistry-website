Request for proposal FAQs

When should we use this page?

Use it when your team needs more than a quick price and expects a written response covering scope, production approach, pricing, timing and delivery assumptions.

What should we attach?

Attach the RFQ, BOQ, TOR, brief, artwork files, sizes, quantities, delivery location, deadline and any submission instructions your organization must follow.

Can Kamog Artistry prepare both technical and financial sections?

Yes. Where the scope requires it, we can prepare a combined response covering execution method, materials, production timing and pricing.

Should pricing-only requests use this page?

No. Use Request Quotation when the item, size, quantity, material and deadline are already clear and the team only needs pricing.
