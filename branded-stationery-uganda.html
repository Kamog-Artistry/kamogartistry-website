Our Process (Fast + Correct + Professional)

What to Send for a Fast Quote

Send this and we’ll quote accurately:

  • Items list: business cards, letterheads, receipts, invoices, delivery notes, etc.
  • Quantities: number of cards / number of books
  • Pages per book: (for receipt/invoice/delivery note books)
  • Duplicate requirement: single, duplicate (carbon), triplicate (if needed)
  • Numbering: yes/no + starting number (if required)
  • Brand files: logo, colors, any existing design reference
  • Deadline: when you need delivery
  • Delivery location: Kampala / Wakiso / Mukono / other
