What to Send for a Fast Stationery Quote

To quote accurately and reduce delays, send:

  • Items list: which stationery you need (e.g., letterheads + envelopes + IDs + invoice books)
  • Quantities: per item
  • Company details: name, contacts, address, website, TIN/VAT details (if applicable)
  • Brand files: logo (and guidelines if available)
  • Book specs: for invoice/receipt books (fields + duplicate/triplicate if needed)
  • ID specs: staff fields (name, title, department, ID number) + photo handling preference
  • Deadline: submission or internal rollout date
  • Delivery location: Kampala / Wakiso / Mukono / other
