Tender / RFQ Upload FAQs

What should I submit on this page?

Submit RFQs, BOQs, TORs, tender files, artwork packs, drawings, specifications, bid notices, supplier checklists, evaluation formats or portal instructions.

Can I paste a Drive or WeTransfer link instead of uploading?

Yes. Paste the file link in the instructions and confirm that access is open. This is better for large artwork folders, BOQ spreadsheets, tender packs or zipped supplier documents.

Can this page cover pricing, proposal and compliance needs?

Yes. Select the response expected and list mandatory documents. Pricing and proposal work can start from this page, while controlled company records should still be handled through Document Request or Compliance.

Should simple price requests use this page?

No. Use Request Quotation when you only need prices for clear items, sizes and quantities without a formal RFQ, BOQ, TOR, tender pack or supplier checklist.
